# Payment Service

## Описание
Payment Service — сервис для оплаты оформленных заказов. (Для максимальной простоты он лишь имитирует поведение процесса оплаты)

## Функциональность
1. **Оплата заказов** — сервис принимает запрос на оплату и выполняет имитацию платежа.
2. **Получение информации о заказе** — запрашивает сведения о заказе у Order Service.
3. **Отправка событий после успешной оплаты:**
    - **Order Service** — обновление статуса заказа и отправка уведомления клиенту.
    - **Inventory Service** — окончательное списание товара из резерва.

## Use Case: Оплата заказа

**Актор:** Клиент

### Предусловия:
- Клиент зарегистрирован в системе.
- Заказ создан и имеет статус `PLACED`.

### Входные данные:
- `UUID заказа` — уникальный идентификатор заказа.
- `UUID клиента` — уникальный идентификатор клиента.

### Сценарий:
1. **Запрос к Order Service**
    - Получение информации о заказе (статус, клиент, товары) по `UUID заказа`.
    - Если заказ не найден или произошла ошибка, процесс оплаты прерывается с возвратом ошибки.
2. **Проверка клиента**
    - Система проверяет, совпадает ли `UUID клиента` с клиентом, указанным в заказе.
    - Если данные не совпадают, операция отклоняется с ошибкой: _"Этот заказ был оформлен другим клиентом"_.
3. **Имитация процесса оплаты**
    - Система выполняет имитацию успешной транзакции.
4. **Завершение оплаты**
    - Отправка события об успешной оплате.
    - Клиент получает подтверждение успешной транзакции.
